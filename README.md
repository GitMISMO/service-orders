# service-orders

**Public.** The MISMO Service Orders and Agreements portal, served by GitHub Pages at
`resources.mismo.org/service-orders/`.

⚠ **This repository holds NO data.** The pages ask the save relay for everything, and the relay
decides what each signed-in person may see. **Never commit a data file, a real company's figures,
a token or a password here.**

- **Working on it?** Read **[DEVELOPING.md](DEVELOPING.md)** first: what it does, where everything
  lives, how a change goes live and how to roll back, sign-in, every connection, and Jonna's rules.
- **Using it?** The **Help** page inside the portal is the user guide.
- **What changed?** [CHANGELOG.md](CHANGELOG.md).
- **Changes go live only through Actions › Publish a Version**, after the checks pass. Never upload
  `index.html` by hand.
